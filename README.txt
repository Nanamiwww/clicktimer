鼠标定时点击器 v1.2 源码
========================
双击 build.bat 即可用 Windows 自带的 C# 编译器生成 ClickTimer.exe（无需安装任何软件）。

文件说明
  Program.cs          程序入口、设置保存（%APPDATA%\ClickTimer\settings.ini）
  MainForm*.cs        主窗口界面与逻辑
  Theme.cs            界面配色与自绘控件（卡片、圆角按钮、输入框外框、状态卡）
  Engine.cs           计时与点击（独立线程 + Stopwatch）
  Picker.cs           定格拾取坐标（放大镜）、屏幕位置标记
  Native.cs           Windows API 调用（SendInput、SetCursorPos/GetCursorPos、DPI、热键等）
  app.ico             程序图标

安全措施
  - 点击前读回光标位置，确认到位才按下；没到位就取消并停止
  - 按下后一定尝试抬起（失败重试 3 次）；只有抬起前确认光标仍在原位、且抬起成功，才记为"已发出"，否则标为"可能未生效"
  - 任何一步失败立即停止，界面如实显示点击了几次、鼠标有没有移开
  - 左键可能仍按着时：不再自动移动鼠标；提示按 F9 在原地松开（在原地松开会完成这次点击）；
    确认松开前「开始」「拾取」保持锁定；退出程序时会先补发一次抬起
  - 拾取：一点「拾取」就先铺上看不见的全屏遮罩接住所有点击，再截图定格；定格画面出现前的点击、
    双击「拾取」的第二下都会被忽略；准备阶段按 Esc 或关闭窗口可直接取消；任何方式结束都会回到主窗口
  - 间隔时间最短 0.1 秒

计时说明
  每次等待的最后 25 毫秒持续等待，不受 Windows 计时器降频（如窗口被遮挡、最小化）的影响；
  运行期间减少 .NET 垃圾回收造成的停顿。实际误差仍受系统负载和线程调度影响，日志里记录每次实测的延迟和间隔。
